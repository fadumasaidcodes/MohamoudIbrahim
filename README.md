# Mohmud Ibrahim Portfolio

Editable React/Vite recreation of the published procurement and contract portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

The compiled website is created in `dist/`.

## Before publishing

1. Replace `your.email@example.com` in `src/main.jsx` with the real email address.
2. Add the LinkedIn URL if required.
3. If the repository is named `YOUR-USERNAME.github.io`, change `base` in `vite.config.js` to `/`.
4. If the repository has another name, set `base` to `'/REPOSITORY-NAME/'`.

## GitHub Pages

The recommended method is to use GitHub Actions to build the project and publish the `dist/` folder. The source files are kept in the repository, while GitHub publishes the generated build.

The portrait is stored locally at `public/images/mohmud-ibrahim-portrait.webp`.
